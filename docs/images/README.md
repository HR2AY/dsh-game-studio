# 市场投稿截图（待补）

市场收录要求 `screenshots` 填 1–5 张**在最终可安装版本上实拍**的产品画面，
图片必须托管在本仓库（这里是 `docs/images/`）。

## 需要拍什么

| 文件名（建议） | 画面内容 |
|---|---|
| `overview.png` | 工作台打开后的三列主界面（游戏列表 / 卡片墙可见） |
| `preview.png` | 选中游戏后的 localhost 实时预览（最左列有真实游戏画面） |
| `paint.png` | 召出右侧画板并画了几笔、或显示「放入对话（PNG）」 |
| `pet.png`（可选） | 右下角 IP 宠物处于思考/运行状态 |
| `session.png`（可选） | 中间列与 AI 对话、改完之后预览自动刷新 |

## 规格

- 格式：静态 PNG / JPEG / WebP（不接受动图）
- 单张 ≤ **2 MiB**，总像素 ≤ 16 MiPixels
- 建议横向 **16:9**、宽度 **≥ 1280px**
- 第一张是封面
- 不得包含凭据、个人信息或客户数据
- 拍完把 `submission/awesome-dsh-workbench.yml` 里的文件名改成本目录下真实文件名

## 为什么由你来拍

Agent 无法操作 DSH Desktop 的图形界面，也没有截屏能力，因此这几张图必须由你在
**已安装的 0.1.18** 上实拍。规范明确要求截图与最终可安装版本相符。
